# Referensi Jurnal Ilmiah Terakreditasi Sinta 1–3 (Poin 7)

Dokumen ini menopang pemilihan metode pengujian pada objek final **Portal Booking GOR Permata Badminton Hall** (`https://gorpermatabadminton.com`) sesuai **Poin 7** instruksi perkuliahan: setiap strategi/metode pengujian wajib disertai justifikasi dan kutipan paper dari jurnal terakreditasi **Sinta 1–3**.

---

## 1. Kandidat Jurnal Terverifikasi Akreditasi Sinta 1–3

> **Catatan Verifikasi:** Status SINTA di bawah dicek dari indeks SINTA (`sinta.kemdikbud.go.id`). Anggota kelompok wajib mengunduh PDF resmi artikel, memverifikasi kembali SK akreditasi terbarunya, lalu menyalin kutipan halaman & temuan riset ke bagian pustaka laporan akhir.

| Metode Pengujian yang Disitasi | Nama Jurnal | Status SINTA Teramati | Judul Paper Relevan | Penerapan di Proyek GOR Permata |
| :--- | :--- | :--- | :--- | :--- |
| **Black Box — Boundary Value Analysis (BVA)** | *Jurnal Informatika Universitas Pamulang* | **Sinta 3** | *Penerapan Teknik Boundary Value Analysis untuk Pengujian Aplikasi Penjualan Menggunakan Metode Black Box Testing* | Menjustifikasi pengujian nilai batas panjang/awalan nomor WhatsApp dan batas jam tutup (`00:00`, misalnya slot `22:00 + 3 jam`) pada form `/booking`. |
| **Black Box — Boundary Value Analysis pada Website** | *Sinkron : Jurnal dan Penelitian Teknik Informatika* (Politeknik Ganesha Medan) | **Sinta 3** | *Feasibility Analysis of Bengkel Koding Website Using Black Box Testing and Boundary Value Analysis* | Menjustifikasi penyusunan skenario BVA dan *Equivalence Partitioning* untuk mengukur kelayakan fungsional portal web booking. |
| **White Box — Basis Path & Cyclomatic Complexity** | *Jurnal Informatika Universitas Pamulang* | **Sinta 3** | *Pengujian White Box pada Aplikasi Cash Flow Berbasis Android Menggunakan Teknik Basis Path* (Citra Teguh Pratala, dkk., Vol. 5 No. 2, 2020) — serta artikel web testing sejenis di jurnal Unpam | Mendukung penyusunan *Flow Graph*, perhitungan *Cyclomatic Complexity* $V(G)$ pada fungsi JavaScript klien `normPhone()` dan `submitBooking()` di `/booking`. |
